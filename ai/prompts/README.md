# Operational Prompts

These files are the durable instructions for human-supervised work and unattended
Codex Cloud publishing. Content rules stay in the two living per-feed documents;
transport, idempotency, and trusted-publication rules stay in the cloud runbook.

| File | Purpose |
| --- | --- |
| `CODEX_CLOUD_RUNBOOK.md` | Codex Cloud primary, catch-up, monitor, fallback, and PR handoff contract |
| `CODEX_CLOUD_TASK_INSTRUCTIONS.md` | Auditable exact template and manifest for all eight server-hosted Scheduled Task prompts |
| `CODEX_FULL_HANDOFF.md` | Full two-feed takeover and supervised recovery guide |
| `MEMEDAILY_DAILY_AUTOMATION.md` | Living meme research, safety, evidence, and JSON rules |
| `DAILYNEWS_DAILY_AUTOMATION.md` | Living news selection, safety, evidence, and JSON rules |
| `UNIFIED_START_PROMPT.md` | Normal session start |
| `NEW_MODEL_HANDOFF_PROMPT.md` | Complete new-model handoff |
| `SYNC_ROUTINE.md` | Mid-session state synchronization |
| `CLOSE_ROUTINE.md` | Tiered session close |
| `PROJECT_KICKOFF_PROMPT.md` | New-project kickoff |
| `SOP_WORKFLOW.md` | General collaboration workflow |
